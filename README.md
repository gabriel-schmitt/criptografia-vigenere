# Criptografia: maquina Enigma

TDE de Estrutura de Dados II (UCS): pesquisa e teste de um algoritmo de criptografia de dados. O algoritmo escolhido e a maquina Enigma (modelo Enigma I, com 3 rotores, refletor e painel de conexoes), implementada em C.

## Enunciado

- Escolher um metodo de criptografia (exceto a cifra de Cesar basica).
- Implementar e executar o metodo, com dois ou mais testes de criptografia.
- Relatorio: descricao do metodo e fontes, testes realizados (textos e resultado cifrado) e codigo da implementacao.

## Compilar e rodar

```
make
./enigma
```
